quanteeze settings

The QUANTEEZE_* variables this server reads: a change is set at once and saved, and takes effect when the server next reads it.
← Overview

Token

The control routes ask for the token the server made at start. Open the URL it printed (with #token=…), or paste the token from ~/.quanteeze/control-token.

Model

Load another model or change expert bit-width without a restart. Requests that generate meanwhile are asked to come back (503) once the running ones finish.
